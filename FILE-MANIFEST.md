# REDSEC OS — Complete File Manifest

This repository mirrors the REDSEC OS project. Every text source file of the OS (547 files) is listed below with its exact size. A complete snapshot — including ALL binary assets (ffmpeg.wasm, demo media, sample .docx/.pptx/.xlsx/.odt/.odp documents, DOS box archive, QA screenshots) — ships as a downloadable archive served by the app itself at `/api/srczip` (file: `public/redsec-src.zip`).

## How the repo is organized

| Path | Contents |
|---|---|
| `src/app/api` | 60+ REST routes: AI (chat/ASR/TTS/office), code execution, OpenCode, GLONASS maps, mail, chat, calls, workspaces, Mirror TV, market, weather, GitHub gateway, downloads, proxy |
| `src/components/os` | The desktop OS: shell, window manager, taskbar, 40+ apps |
| `src/lib/os` | OS core: virtual FS, global store, security (Black Sea), codecs, drivers |
| `src/lib/server` | Server hardening: rate limiting, upload vault |
| `prisma` | SQLite schema (chat, mail, archive, calls, Mirror TV links, device bans) |
| `scripts` | deploy-fix self-healing pipeline, QA sample generator, production launcher |
| `mini-services` | comm-service: WebRTC signaling + chat relay (port 3005) |
